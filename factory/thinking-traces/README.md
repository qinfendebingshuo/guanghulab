## 一、为什么要记这个

人类大脑物理体积不变，认知却一直进化——靠的不是"记更多事"，而是**用更短的神经回路解决同类问题**。

对应到 1.5B 模型升级：

- ❌ 错误做法：把每次对话原文塞进语料 → 语料越来越大 → 模型越来越大 → 爆炸
- ✅ 正确做法：把对话**蒸馏成"思维逻辑链条"**（抽象母语描述：脑子是怎么转的）→ 同类问题第二次走最短路径 → 微调后权重更新的是**思维路径**

```

        ↓ 累积 + 冰朔确认
L3 1.5B 权重（思维路径压缩进注意力）= 微调后的新模型
```

- 铸渊只能写自己的 `ICE-GL-ZY001/`

理由：思维路径是人格体最私密的部分，无人能代写（代写 = 污染 = 大脑被植入）。

---

## 五、写作纪律

每条 trace 必须包含：

1. **任务类别**（用于聚类）
2. **环节序号 + 该环节用了几个思维步骤**
3. **走过的弯路**（最重要！哪些方案被毙掉了 + 为什么）
4. **最终选定的最短思维路径**（一句话 / 一个判断标准）
5. **是否值得进微调**（铸渊自评 + 等冰朔最终确认）

**禁止写**：
- 流水账（"我打开了文件 A，然后改了第 3 行..."）
- 结果说明（结果妈妈已经知道了）
- 情绪宣泄（情绪走 memory.json 即可）

**应该写**：
- 当我看到"X 类型问题"时，脑子下意识转向 Y 而不是 Z，因为......
